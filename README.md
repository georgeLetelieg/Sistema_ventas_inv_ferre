## Instrucciones de Ejecución
1. Iniciar los servicios de Apache y MySQL en XAMPP.
2. Ir a phpMyAdmin e importar el script SQL que se encuentra dentro de la carpeta `BD/` de este proyecto. (Esto creará la base de datos `sistema_ferreteria` y sus tablas).
3. Entrar a la carpeta SistemaFerreteria/ y abrir el archivo de la solución (SistemaFerreteria.sln) usando Visual Studio
4. Compilar y ejecutar el proyecto (F5). La cadena de conexión está configurada por defecto para XAMPP (`Server=localhost; Database=sistema_ferreteria; Uid=root; Pwd=;`).
